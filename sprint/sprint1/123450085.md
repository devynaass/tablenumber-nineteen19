# Sprint 1 - 123450085

*Jalur:* RNN → CNN-LSTM atas urutan strip baris citra
*Tugas sampingan:* Reproduksi & Demo

## Selesai

Pada Sprint 1 ini, saya telah menyelesaikan persiapan bahan slot dan latihan kering dengan menyiapkan satu set objek fisik tetap untuk 8 kelas objek meja beserta alas kertas A3, serta menyusun panduan checklist penataan di `docs/kartu/checklist_latihan_kering.md`. Selain itu, saya mengembangkan skrip generator berbasis spesifikasi `t19-objek-meja.yaml` yang berhasil memproduksi folder sesi simulasi 120 kondisi (`label.csv` dan `manifest.json`) di `data/simulasi/sesi_t19/` untuk kebutuhan Penjaga Data, serta menyusun dokumen 30 kartu susunan resmi S01–S30 dalam format PDF cetak dan CSV di `docs/kartu/`.

Pada jalur model RNN, saya telah mengimplementasikan arsitektur **CNN-LSTM** pada `models/123450085/model.py` yang memproses urutan 7 strip baris citra 224×224 secara sekuensial. Pipeline eksekusi dibangun di `models/123450085/run.py` dengan ketentuan berikut:

- **Data:** data primer meja tim 19 (`sesi-20261116-165743`) via `src.protokol.data.muat()` — 384 sampel latih, 96 sampel validasi
- **Task:** regresi (prediksi jumlah objek 8 kelas per citra)
- **Loss:** MSELoss
- **Optimizer:** Adam (lr=1e-3)
- **Seed:** 1

### Hasil Evaluasi – Data Validasi (Seed 1)

| Metrik | Nilai |
|--------|-------|
| val_rmse | 0.6613 |
| val_mae | 0.5132 |
| val_r2 | -1.5588 |
| Durasi pelatihan | 46.9 detik (CPU) |

> R² negatif pada Sprint 1 adalah wajar — model baru dilatih 5 epoch dengan arsitektur dasar tanpa tuning. Peningkatan akan dikerjakan di Sprint 2 (3 seed, hyperparameter tuning, perbandingan lengkap).

Berkas `results/123450085/metrics.json` telah tervalidasi melalui `src.common.evaluate` (mencakup `data_hash` sesuai MANIFEST tim) dan `results/123450085/pred_val.npy` tersimpan. Seluruh kode dan hasil telah di-commit ke branch `123450085/kerja`.

## Berikutnya

Pada Sprint 2, fokus utama adalah:
1. Melatih ulang dengan **3 seed** (1, 2, 3) untuk mengukur stabilitas model
2. **Hyperparameter tuning**: jumlah strip, hidden dim LSTM, learning rate
3. Perbandingan lengkap dengan baseline non-DL tim
4. Menyiapkan video demonstrasi Sprint 1 (Tugas #10 – Reproduksi & Demo)

## Hambatan

Pada Sprint 1, pipeline awal menggunakan data simulasi dan CrossEntropyLoss (tidak sesuai task regresi). Hambatan ini telah diselesaikan dengan menghubungkan `run.py` ke data primer via `src.protokol.data.muat()` dan mengganti loss menjadi MSELoss, sehingga `metrics.json` kini valid dengan `data_hash` yang sesuai MANIFEST tim.
