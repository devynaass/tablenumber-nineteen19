# Sprint 1 - 123450085

*Jalur:* RNN -> LSTM/GRU atas baris citra 
*Tugas sampingan:* Reproduksi & Demo

## Selesai
Pada Sprint 1 ini, saya telah menyelesaikan persiapan bahan slot dan latihan kering dengan menyiapkan satu set objek fisik tetap untuk 8 kelas objek meja beserta alas kertas A3, serta menyusun panduan checklist penataan di docs/kartu/checklist_latihan_kering.md. Selain itu, saya mengembangkan skrip generator berbasis spesifikasi t19-objek-meja.yaml yang berhasil memproduksi folder sesi simulasi 120 kondisi (label.csv dan manifest.json) di data/simulasi/sesi_t19/ untuk kebutuhan Penjaga Data, serta menyusun dokumen 30 kartu susunan resmi S01 sampai S30 dalam format PDF cetak dan CSV di docs/kartu/.

Pada jalur model RNN, saya telah mengimplementasikan arsitektur CNNLSTM pada models/123450085/model.py yang memproses urutan 7 strip baris citra 224×224 secara sekuensial, menyiapkan data simulasi citra di data/simulasi/, dan membangun pipeline eksekusi di models/123450085/run.py. Pengujian skrip menggunakan seed 1 berhasil berjalan tuntas dari awal hingga akhir dalam durasi 5,25 detik pada CPU laptop serta sukses menghasilkan berkas luaran results/123450085/pred_val.npy dan metrics.json. Seluruh kode, dokumen kartu, dan hasil uji tersebut telah saya commit dan push ke branch 123450085/kerja di repositori GitHub tim.
