## 2. Data yang Digunakan

Dataset dimuat menggunakan loader resmi tim melalui `src/protokol/data.py`, dengan fungsi `data.muat()`.

| Pembagian | Jumlah data | Bentuk X | Bentuk y |
|---|---:|---|---|
| Train | 384 | (384, 3, 224, 224) | (384, 8) |
| Validasi | 96 | (96, 3, 224, 224) | (96, 8) |
| Test | 241 | (241, 3, 224, 224) | (241, 8) |

Loader juga mengembalikan 241 sampel data test. Namun, evaluasi Sprint 1 hanya dilakukan pada data validasi sebanyak 96 sampel. Data test belum dievaluasi, sebagaimana ditunjukkan oleh nilai n_test=0 pada metrics.json.

Input citra menggunakan tipe `float32` dengan rentang nilai 0–1. Target merupakan jumlah objek dari delapan kelas.

Normalisasi fitur dihitung berdasarkan data training dan diterapkan pada data validasi.

## 3. Konfigurasi Model

Model menggunakan arsitektur Patch Transformer dengan konfigurasi:
- Patch embedding menggunakan Conv2D dengan 64 kanal.
- Ukuran patch 16 × 16.
- Positional embedding untuk 196 patch.
- Dua Transformer encoder layers.
- Empat attention heads.
- Feedforward dimension 128.
- Output regresi sebanyak delapan kelas.

Pelatihan menggunakan AdamW dengan learning rate 0.001 dan Mean Squared Error sebagai loss function.
